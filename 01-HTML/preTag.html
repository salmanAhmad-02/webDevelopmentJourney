Java Code For Inheritance 


            class Animals{
                String name;
                public void eats(){
                    System.out.println(name + "is eating");
                }
            }
            class Cat extends Animals{
                public void meow(){
                    System.out.println(name + " Says Meaw Meaw");
                }
            }
            public class HavingMain{
                public static void main(String[]args){
                    Cat obj1=new Cat();
                    obj1.name = "Max";
                    obj1.eats();
                    obj1.meow();
                }
            }
        

            
Output
            Max is eating 
            Max says Meaw Meaw

All above code are displayed as it is on the display as it written , that all done by using pre tag
